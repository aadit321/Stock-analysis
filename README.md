# 📊 Asian Paints Stock Analysis Dashboard

## 📌 Project Overview

This project is an interactive **Power BI dashboard** created to analyze the stock performance of **Asian Paints** over time.

The dashboard provides insights into stock prices, trading volume, VWAP, yearly trends, and daily trading activity. It helps users understand the company's stock performance and identify important trends and fluctuations.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze Asian Paints stock price trends over time.
- Track Open, High, Low, and VWAP values.
- Analyze yearly trading volume.
- Monitor daily trading activity.
- Identify significant changes in stock performance.
- Create an interactive and easy-to-understand dashboard using Power BI.

## 📈 Dashboard Features

### 1. VWAP Analysis

The dashboard shows the yearly trend of **Volume Weighted Average Price (VWAP)**.

It helps identify how the average traded price changed over different years.

### 2. Open Price Analysis

The **Open Price by Year** visualization helps analyze changes in the opening stock price over time.

### 3. Trading Volume Analysis

The dashboard provides yearly trading volume analysis to identify periods of high and low trading activity.

### 4. Intraday Analysis

The intraday chart provides a visual representation of stock price movement during the selected period.

### 5. Daily Trading Volume

The dashboard includes a gauge showing the volume of trades per day.

### 6. Interactive Date Filters

Users can select different dates using the slicer to dynamically filter the dashboard.

## 💡 Key Insights

Based on the dashboard analysis:

- Asian Paints experienced significant growth in stock price until around **2013**.
- A sudden decline in stock price was observed after the growth period.
- Increased prices of key raw materials, particularly **crude oil derivatives**, can put pressure on margins.
- Trading volume increased significantly during certain periods.
- The dashboard shows considerable variation in stock price and trading activity across different years.
- The intraday analysis helps identify short-term price movements.

> **Note:** These observations are based on the dataset and dashboard analysis and should not be considered financial advice.
